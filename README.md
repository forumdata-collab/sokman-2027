2027 丁未羊年十二生肖運程網站 — 一個以蘇民峰《生肖運程》文風生成嘅單頁靜態網站。曆法數據（干支／節氣月／九宮飛星／太歲沖合刑害）由開源曆法庫 `cnlunar` 客觀計算，運程文字由 AI 生成。

> **⚠️ 聲明（Disclaimer）：** 本網站所有內容均由 AI 生成，**並非蘇民峰親筆，亦未經任何命理專業人士審閱，僅供娛樂參考。** 請勿以網站內容作任何實際決策依據。

## 功能

- **十二生肖全年運程** — 12 個生肖章節，每款約 4,000 字：年度總評／吉凶星／寒熱平三命／出生年分代／農曆十二月逐月運程
- **九宮飛星互動格（九宮飛星）** — 2027 年飛星圖，點擊任意宮位查看星曜詳情
- **犯太歲速查** — 輸入出生年份即知是否犯太歲（值／沖／刑／害），以及化解建議
- **寒熱平三命計算器** — 輸入出生日期即可得知寒熱平三命類別及 2027 年宜忌
- **出生年分代** — 十二生肖出生年分代對照，配合運程文字使用
- **農曆逐月運程** — 每個生肖額外附 12 個月嘅逐月運程分析

### 2027 丁未年曆法重點

- 丁未年 · 九紫入中
- 太歲方位：西南 ｜ 歲破方位：東北 ｜ 三煞方位：西方
- 犯太歲生肖：羊（值）／牛（沖）／狗（刑）／鼠（害）

## 技術棧（Tech Stack）

| 層面 | 技術 |
|---|---|
| 曆法引擎 | [cnlunar](https://github.com/LiteSoul/cnunar)（開源）— 干支／節氣月／飛星／太歲 |
| 內容生成 | Python + AI，按蘇民峰文風生成（由掃描書本 OCR 提取風格模板） |
| 網站建置 | Python 靜態站點生成器 → 輸出單頁 `index.html` |
| 語言 | 繁體中文（粵語語感） |
| 部署 | 純靜態 HTML，手機友好，無需伺服器／零依賴 |

## 建置（Build）

```bash
# 1. 安裝 Python 依賴
pip install cnlunar

# 2. 建置單頁靜態網站
python3 build_site.py
```

建置管線：

1. `compute_facts.py` — 以 cnlunar 計算 2027 年節氣月干支／飛星／太歲方位等客觀曆法數據
2. `generate_2027.py` — 以蘇民峰文風生成十二生肖運程章節
3. `build_site.py` — 組合成單頁靜態站

輸出：`index.html`（單檔、自帶樣式，直接以瀏覽器開啟即可）。
