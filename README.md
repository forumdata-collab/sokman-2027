> **以蘇民峰命理體系（五行生剋推理）重建一年十二生肖運程，並以原書內容認證每一條規則。**

本站是 **2027 丁未羊年十二生肖運程**單頁應用，其核心不是「抄襲某一年的預測」，而是把蘇民峰曆書中的 **可推演規則** 蒸餾成一個推理引擎，再按年份重新計算——吉凶星、九宮化解物、大門地氈色、犯太歲飾物、熱平寒分類等，全部由五行生剋推導。

```
   📖 原書（癸卯兔年運程等曆書）
        │  OCR + 精讀
        ▼
   🧠 knowledge_base.json（蘇氏推理規則庫）
        │  五行生剋推演引擎
        ▼
   🌐 index.html（互動單頁站，按所選年份即時重新推算）
        ▲
   🔍 audit_logic_su.py（以書內容認證每一條推理，防止抄錯/過時）
```

## 🧠 蒸餾的核心推理（蘇氏獨門邏輯）

項目不只展示答案，更把 **推理背後的原因** 寫進 `knowledge_base.json`，並由書內容認證。以下為六層規則庫摘要：

### 1. 九宮化解物品（`九宮化解`）

以星曜五行定化解：凶星以相洩化解——二黑五黃（土）→音樂盒（金泄土）、三碧（木）→粉紅色物件（火泄木）；吉星以相生催旺——八白（財土）→一杯水、九紫（喜火）→四盆植物九枝紅花（木生火）。

### 2. 五行化動土局（書 p25-29 · 蘇氏 1997 自創）

對門裝修動土煞的化解法——**起手物＝剋制煞方位元素，餘者依相生鏈倒序周流**（五行周流不滯，煞氣不能侵入）：

| 煞方位 | 五物順序（依書） | 起手剋煞 |
|---|---|---|
| 南方（火煞） | 水、音樂盒、石頭、紅色物件、植物 | 水剋火 ✓ |
| 西南／東北（土煞） | 植物、水、音樂盒、石頭、紅色物件 | 木剋土 ✓ |
| 西方／西北（金煞） | 紅色物件、植物、水、音樂盒、石頭 | 火剋金 ✓ |
| 北方（水煞） | 石頭、紅色物件、植物、水、音樂盒 | 土剋水 ✓ |

*已通過書證：4/4 方位起手規則自洽，五行相生環成立。*

### 3. 大門地氈旺宅化病法（書 p47-51）

每年飛星隨方位流轉，大門開向不同方位迎入吉凶星，以特定地氈色及化解物調和：

| 大門開向之飛星 | 地氈／化解物 | 原理 |
|---|---|---|
| 八白財星 | 紅色地氈（門外） | 火生土催財 |
| 九紫喜慶 | 綠色地氈（室外） | 木生火催喜慶 |
| 六白武曲 | 黃啡色（外）＋灰色（內） | 土生金利武職升遷 |
| 二黑／五黃凶土 | 灰色氈＋金屬件／風鈴／音樂盒 | 金泄土化煞 |
| 三碧木煞 | 粉紅色地氈 | 火泄木化是非 |
| 七赤金煞 | 灰色氈（屋內）或一杯水 | 金生水洩 |

*已通過書證：9/9 方位與原書相符。*

### 4. 犯太歲飾物（書 p18）

佩戴 **當年太歲生肖** 的三合／六合飾物（合太歲）；若該三合／六合生肖自身亦犯太歲則**不可佩戴**（避免相沖複疊）。書載案例：肖雞（沖太歲）戴狗形鏈墜（兔年六合）；肖龍放羊豬形擺設（兔年三合）。

### 5. 熱平寒（蘇民峰官方定義）

| 命格 | 出生期間 | 喜用 |
|---|---|---|
| 寒命 | 立秋後至驚蟄前（跨年） | 火（木生火） |
| 熱命 | 立夏後至立秋前 | 水（金生水） |
| 平命 | 驚蟄後至立夏前（清明前較平、後較熱） | 水（喜水不忌火；以水運較佳） |

### 6. 動土戒條（書 p14-15）

三煞方、太歲方、五黃方不宜動土；五黃在大門／廚房最嚴重（灰氈墊底＋銅片＋音樂盒＋風鈴）；二黑方最不利女主人（腹部腸胃病）。

## 🔬 認證系統

每個推理皆有書證，執行 `audit_logic_su.py` 自動驗證：

```bash
python3 audit_logic_su.py
```

輸出四項認證：
- **A. 五行化動土局** — 書載序列 vs 五行推演（起手剋煞＋相生環，4/4）
- **B. 大門地氈** — 書載規律 vs 星五行推演（9/9）
- **C. 九宮化解** — 書載物品 vs 星五行原理（9/9）
- **D. 犯太歲飾物** — 書載案例 vs 三合六合規則

亦有 `verify_su_rules.py` 驗證網站展示資料與知識庫一致。

## 🚀 建置與快速開始

```bash
# 1. 建置單頁站（Python 3.8+，純標準庫，無第三方依賴）
python3 build_site.py        # → 生成 index.html

# 2. 認證推理正確性（以書內容驗證）
python3 audit_logic_su.py

# 3. 驗證網站資料與知識庫一致
python3 verify_su_rules.py
```

> 重建可重現性已驗證：由源碼在空目錄重建的 `index.html` 與發布版 SHA256 完全一致。
