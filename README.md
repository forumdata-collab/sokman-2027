# 2027 丁未羊年 十二生肖運程（AI 風格生成）

2027 丁未羊年十二生肖運程 — 曆法數據（干支／節氣月／九宮飛星／太歲沖合刑害）由開源曆法庫 `cnlunar` 計算（客觀可驗），運程文字由 AI 按蘇民峰《生肖運程》文風生成。**非蘇民峰親筆，僅供娛樂參考。**

![badge](https://img.shields.io/badge/year-2027%20%E4%B8%81%E6%9C%AA-orange)

## 功能
- 十二生肖全年運程（每款 ~4,000 字：年度總評／吉凶星／寒熱平三命／出生年分代／農曆十二月逐月運程）
- 客觀曆法數據：2027 丁未年 · 九紫入中 · 太歲方位西南 · 歲破東北 · 三煞西方
- 犯太歲生肖標記：羊（值）／牛（沖）／狗（刑）／鼠（害）
- 單頁靜態站，手機友好，零依賴

## 目錄
```
index.html          成品網頁（單檔，自帶樣式）
sokman-2027/        生成管線（腳本只喺本機運行，唔含 PDF）
```

## 生成管線（本地）
1. `compute_facts.py` — cnlunar 計算 2027 年節氣月干支／飛星／太歲方位
2. `generate_2027.py` — 以蘇民峰文風（由掃描書 OCR 提取風格模板）生成十二生肖章節
3. `build_site.py` — 組合成單頁靜態站
